# Changelog

Все важные изменения в этом проекте будут документироваться в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0] - 2026-10-30

### Added

- Базовая структура проекта (папки html, css, js, img).
- Главная страница с навигацией, акциями и кнопкой бронирования.
- Страницы каталога: сашими, суши, роллы.
- Страница прайс-листа с табличной версткой.
- Страницы бронирования столика и заказа еды на вынос.
- Интерактивный чат-бот поддержки на чистом JavaScript.
- Замена всех эмодзи на векторные SVG-иконки для улучшения стилизации и производительности.
- Файлы документации: README.md и CHANGELOG.md.
